# Демо-лендинги для малого бизнеса

Четыре одностраничных сайта для портфолио. Компании вымышленные. Сайты специально сделаны разными:
у каждого своя палитра, свои шрифты и своя композиция первого экрана — это не один шаблон
в разных цветах.

**Витрина:** https://vit3ma3.github.io/landing_demo/

## Стек

- Чистые HTML, CSS и vanilla JS — без сборщиков, фреймворков и зависимостей.
- Mobile-first вёрстка, проверена на ширине 375 px и на десктопе.
- Мета-теги для превью ссылки (Open Graph, Twitter Card), favicon и иконка для iOS у каждого сайта.
- Шрифты из Google Fonts (лицензия SIL OFL). Чужих фото и логотипов нет: вся графика нарисована
  на CSS и SVG, фото заменены градиентными заглушками.
- Формы в демо только проверяют поля и показывают сообщение об успехе — данные никуда не уходят.
  Как подключить отправку заявок в Telegram без раскрытия токена — в [remont/README.md](remont/README.md).

## Структура

```
index.html                витрина со ссылками на все сайты
assets/                   favicon и превью витрины
massage/ photo/ remont/ coffee/
  index.html              страница
  css/style.css           стили — у каждого сайта свои
  js/main.js              меню, аккордеоны, формы, калькулятор и т. п.
  assets/                 favicon.svg, apple-touch-icon.png, og-image.png (1200×630)
.nojekyll                 отключает обработку Jekyll на GitHub Pages
```

Каждая папка самодостаточна: её можно скопировать в отдельный репозиторий или на хостинг клиента.

## Локальный просмотр

Откройте `index.html` в браузере — больше ничего не нужно.

## Публикация на GitHub Pages

1. **Settings** → **Pages** → **Build and deployment** → **Source: Deploy from a branch**.
2. **Branch:** `main`, папка `/ (root)` → **Save**.
3. Через 1–2 минуты сайт появится по адресу `https://<логин>.github.io/<репозиторий>/`.

Если репозиторий переименован или опубликован под другим аккаунтом, поправьте абсолютные ссылки
`og:url` и `og:image` в `index.html` каждого сайта. Мессенджеры берут картинку превью только по полному адресу.

## Как адаптировать под реального клиента

- Цвета и шрифты — переменные в начале `css/style.css` каждого сайта.
- Заглушки фото — замените блоки-градиенты на `<img>` с реальными снимками.
- Контакты и ссылки на мессенджеры — в `index.html` (телефон `+7 900 000-00-00` везде вымышленный).
- Картинка превью — `assets/og-image.png`, 1200×630.
